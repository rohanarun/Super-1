# Source binding

Independent implementations of published recurrence equations, adapted to the pinned Super-1 hierarchy. Neither full external language-model architecture is reproduced. No external kernel is imported.

- minGRU: Feng et al., [Were RNNs All We Needed?](https://arxiv.org/html/2410.01201v3), section 3 and appendix B. Official [minRNNs implementation](https://github.com/BorealisAI/minRNNs/blob/ff52e9de9b470ad750fcf09d3c140a6ae29aa1ce/models/minRNNs.py), commit `ff52e9de9b470ad750fcf09d3c140a6ae29aa1ce`. We use the positive candidate function from the numerically stable variant, zero initial state, and a direct affine tree scan. We omit the full block's convolution/extra output projection; the hierarchy supplies its readout. The official source was inspected, not vendored; its repository license is CC BY-NC-SA 4.0.
- ParaGRU: [ParaRNN: Unlocking Parallel Training of Nonlinear RNNs for Large Language Models](https://arxiv.org/html/2510.21450v2), equations 3.1 and diagonal Jacobian. Official [GRUDiagMH](https://github.com/apple-aiml-research/ml-pararnn/blob/513d75dade40843bb27ac4a521969997188b5459/pararnn/rnn_cell/gru_diag_mh.py), commit `513d75dade40843bb27ac4a521969997188b5459`. One head/dense input projection, diagonal recurrent vectors; nonlinear reset/update/candidate retained. Initial guess f(0,x); Newton forward, recurrence-adjoint backward. Our CPU implementation accepts nonzero chunk initial states and uses explicit tolerance checking. No Apple CUDA source was copied. Initialization follows the paper's small normal diagonal weights and L2 cap, not the repository's configurable default xLSTM bias schedule.
- Native hierarchy: [Super-1 source](https://github.com/rohanarun/Super-1/blob/e9afef41fe85de826e8edc97dcf2ffeb6917f2f3/auto-research/results/cloud-recovery-20261015/exact-historical-source/representation_experiments/predictive_models.py), `HierarchicalDistributionStudent`, commit `e9afef41fe85de826e8edc97dcf2ffeb6917f2f3`. Unchanged core source is included in vendor/representation_experiments with its MIT license. Native GRUCell tensors are copied byte-for-byte into an nn.GRU sequence module. Slow GRUs, 32-token/8-segment clocks, boundary readout semantics and tied output table remain.

An affine scan combines (a,b) pairs by `(a2*a1, b2+a2*b1)`. That algebra is exact; floating-point association changes rounding. The local Hillis-Steele tree does O(T log T) work and O(log T) stages, for T <= 32 inside this hierarchy. It is not an optimized work-efficient GPU scan.

PyTorch's native GRU uses the keep-gate convention and applies reset to the recurrent candidate projection. Our ParaGRU follows its source's write-gate convention and reset-before-diagonal-candidate equation. These are specified architectures; ParaGRU is not an exact acceleration of the dense native GRU.

This longer run uses only the linear-candidate minGRU equation g(u)=u. Positive minGRU is historical context only. Three models are reinitialized with seed101602 and trained for2000 updates; the slow hierarchy and recurrent equations are unchanged from the preceding screen.
